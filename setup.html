Mac Dotfiles Setup

Step-by-step guide to setting up this development environment on a fresh Mac. Check off sections as you go — progress is saved in your browser.

Neovim tmux Zsh fzf LSP vim-plug
Prerequisites
▾
Step 1 — Xcode Command Line Tools

Provides git, clang, and other essential build tools. A dialog will appear prompting you to install.

xcode-select --install
Step 2 — Homebrew

The package manager used for almost everything in this setup. After install, follow any instructions it prints about adding brew to your PATH.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

On Apple Silicon Macs, add Homebrew to your PATH:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
Step 3 — Node.js

Required for yarn (vim-prettier) and the language servers installed later.

brew install node
✓ Verify
  • brew --version prints a version number
  • node --version prints a version number
Clone the Repo
▾
Important: The repo must be cloned to ~/dotfiles. The zshrc sources files using the hardcoded path ~/dotfiles/zsh/, so any other location will break the shell config.
git clone https://github.com/wyattsweet/dotfiles.git ~/dotfiles
✓ Verify
  • ls ~/dotfiles shows vimrc, zshrc, tmux.conf, etc.
Zsh + Oh-My-Zsh
▾
Note: Zsh is the default shell on macOS Catalina (10.15) and later. Skip the install step if echo $SHELL prints /bin/zsh.
Step 1 — Install Oh-My-Zsh

Manages the zsh theme and plugins. The avit theme and vi-mode plugin are configured in the zshrc.

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
Step 2 — Install zsh-syntax-highlighting

Highlights valid commands as you type. Must be installed into the Oh-My-Zsh custom plugins directory.

git clone https://github.com/zsh-users/zsh-syntax-highlighting.git \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
Step 3 — Symlink zshrc

Back up the generated ~/.zshrc, then symlink the dotfiles version.

mv ~/.zshrc ~/.zshrc.bak
ln -s ~/dotfiles/zshrc ~/.zshrc
Step 4 — Reload the shell
source ~/.zshrc
Optional: The zshrc sources ~/.alias_local.zsh if it exists — use this for machine-specific aliases you don't want in the repo.
✓ Verify
  • Open a new terminal — commands light up with syntax highlighting as you type
  • The prompt uses the avit theme (git branch shown when inside a repo)
Tmux + TPM
▾
Step 1 — Install tmux
brew install tmux
Step 2 — Install TPM (Tmux Plugin Manager)

TPM manages tmux plugins — the equivalent of vim-plug for tmux.

git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
Step 3 — Symlink tmux.conf
ln -s ~/dotfiles/tmux.conf ~/.tmux.conf
Step 4 — Install tmux plugins

Start tmux, then press Ctrl-f then I (capital I) to install plugins. This installs tmux-resurrect for session persistence.

tmux
Mac clipboard note: The config uses xclip for the y copy binding, which is Linux-only. On Mac, edit ~/.tmux.conf and change that line to:
bind-key -T copy-mode-vi y send-keys -X copy-pipe "pbcopy"

Key bindings reference

prefix o/OCycle panes (zoom-aware)

✓ Verify
  • tmux starts without errors
  • Ctrl-f is the prefix — Ctrl-b should do nothing
  • Split a pane (prefix %) and navigate between them with prefix h/l
  • TPM installed successfully — you saw the "Done" message after pressing prefix I
Neovim
▾
Step 1 — Install Neovim
brew install neovim
Step 2 — Create config directory
mkdir -p ~/.config/nvim
Step 3 — Symlink config files
ln -s ~/dotfiles/vimrc ~/.config/nvim/init.vim
ln -s ~/dotfiles/autoload ~/.config/nvim/autoload
ln -s ~/dotfiles/ftplugin ~/.config/nvim/ftplugin
Step 4 — Symlink snippets

UltiSnips looks for custom snippets in ~/.vim/mysnippets.

mkdir -p ~/.vim
ln -s ~/dotfiles/mysnippets ~/.vim/mysnippets
Optional: Create ~/.config/nvim/local.vim for machine-specific Neovim settings — it's sourced automatically if present.
✓ Verify
  • nvim opens (it will show errors about missing plugins — that's expected until vim-plug is installed next)
  • :echo $MYVIMRC inside nvim shows /Users/you/.config/nvim/init.vim
vim-plug & Plugins
▾
Step 1 — Install yarn

The vim-prettier plugin runs yarn install during setup.

brew install yarn
Step 2 — Install vim-plug
sh -c 'curl -fLo "${XDG_DATA_HOME:-$HOME/.local/share}"/nvim/site/autoload/plug.vim --create-dirs \
  https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim'
Step 3 — Install all plugins

This downloads and installs all 27 plugins. It may take a minute — vim-prettier in particular runs a yarn install.

nvim +PlugInstall +qall

The Silver Searcher (ag)
▾

ag is a fast code search tool used as the default fzf file discovery command and as Neovim's grepprg. The :Ag command and Spaces search in Neovim both depend on it.

brew install the_silver_searcher
✓ Verify
  • ag --version prints a version number
fzf
▾

fzf is used throughout the config — file/buffer search in Neovim, interactive git branch switching (gb), tmux session switching (tm), and file opening (fo).

Step 1 — Install fzf
brew install fzf
Step 2 — Install shell integration

Generates ~/.fzf.zsh, which is sourced by the zshrc.

$(brew --prefix)/opt/fzf/install --all
✓ Verify
  • fzf --version prints a version number
  • Inside nvim, Spaceo opens the fuzzy file finder
  • The shell alias gb opens an interactive fzf branch picker
Language Servers
▾

Two LSP servers are configured in the vimrc Lua block and will auto-attach when you open relevant files.

Pyright — Python

Provides type checking, go-to-definition, and hover docs for Python files.

npm install -g pyright
ESLint LSP — JavaScript / TypeScript

Provides in-editor ESLint diagnostics for JS/TS files.

npm install -g vscode-langservers-extracted
Note: Language servers only activate when the relevant config files (tsconfig.json, .eslintrc, pyrightconfig.json) exist in your project root.
✓ Verify
  • Open a .py file in a project — hover over a symbol with K to see pyright docs
  • Open a .ts or .js file — ESLint diagnostics appear as you type
Git Config
▾
Step 1 — Symlink gitconfig and gitignore
ln -s ~/dotfiles/gitconfig ~/.gitconfig
ln -s ~/dotfiles/gitignore ~/.gitignore
Step 2 — Update name and email
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
✓ Verify
  • git config user.name and git config user.email show your correct details
iTerm2 Color Theme
Optional ▾

A light iTerm2 color profile is included at ~/dotfiles/iterm/Light theme.json.

  1. Open iTerm2 → Preferences → Profiles → Colors
  2. Click Color Presets… in the bottom right
  3. Select Import…
  4. Navigate to ~/dotfiles/iterm/Light theme.json and open it
  5. Select the imported preset from Color Presets… to apply it
✓ Verify
  • The terminal background and colors match the light theme
